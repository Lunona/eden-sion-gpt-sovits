# eden* 诗音 GPT-SoVITS 语音模型

诗音（シオン / Sion）的日语语音模型，附带可自行导入音频的本地参考库界面。基于 GPT-SoVITS v2ProPlus；由游戏日文语音微调，用于角色语音生成实验。

## 下载与使用

在 [Releases](../../releases) 下载 `sion-v1.0.0-no-reference-audio.zip`，解压后包含两份权重及参考库界面；不附带原作音频、台词或剧情摘录，参考库初始为空。本包不包含 Python、CUDA、GPT-SoVITS 程序和通用预训练依赖；需先按 [GPT-SoVITS 官方项目](https://github.com/RVC-Boss/GPT-SoVITS) 安装完整环境，包含 v2ProPlus、日语文本前端、HuBERT/BERT 等对应依赖。

已验证的上游提交：`1b47ca07ef43a284e0b8bd7f29d3e1e3ff76082a`。参考库使用 Gradio 4.44.1。其他上游版本的 API 可能不同。

普通 WebUI：分别选择 `models/sion-pause-supplement-lr002-e2.ckpt` 与 `models/sion-timbre-lr00002_e8_s1392.pth`；参考和目标语言均选日语，使用参考对应的准确原文。

附带参考库（Windows PowerShell）：

```powershell
.\启动参考库.ps1 -AppPath "你的GPT-SoVITS程序目录" -Python "该环境的python.exe路径"
```

浏览器打开 http://127.0.0.1:9882/ 。可按语气筛选、试听、选用一条主参考、导入自己的3–10秒参考，并保存生成参数。只监听本机。关闭启动终端可停止服务。

参考文件路径均相对于解压目录。生成固定 speed=1，未作整体或局部调速、滤波。自然句号切分调用上游原生切分及段间停顿。多个语气是可切换参考，不是混合多条参考，也不是仅靠情感标签控制。

## 效果与限制

同一句日文、同一参考、同一种子、原速比较：优化前／单结束标记第3轮／停顿补样第2轮的声纹余弦分别为0.8758／0.8998／0.9160，活动跨度相对原声误差分别15.9%／20.3%／11.5%。这些是单句指标，不是还原百分比。

开发集6句×2种子，三者声纹余弦均值分别0.8255／0.8374／0.8384，节奏误差中位数23.6%／16.8%／19.2%。发布组合的音色指标领先，但部分节奏指标由另一候选领先；不能宣称所有场景最好。此 GPT 组合尚未完成新的独立最终验收，之前其他组合的20条验收不等于本组合通过验收。

「一度」开头局部节奏和部分停顿仍有偏差；噪声与主观音色仍需试听判断。原声语义重建只用于诊断，不计入普通文本生成排名。

## 自行加入参考音频

原作：minori《eden*》。本项目不提供原作音频下载，也不提供原作安装包或提取素材。请自行从合法持有的原作准备你有权使用的参考音频。

首次打开参考库后，展开“加入新的参考音频”，上传3–10秒、单一角色、完整清晰的短句，填写准确日文原文、名称和语气，再点击“加入参考库”。随后即可筛选、试听和生成。库中只有你自行导入的参考；不会自动下载原作素材。

选择自然、与目标语气接近的录音，避开背景音乐、其他角色、严重噪声或截断句尾。分类用于查找参考，实际情绪迁移仍需试听判断。购买原作不等于获得公开传播其音频的许可，请勿把导入的原作音频随修改版本重新发布。
