# eden* 诗音 GPT-SoVITS 语音模型

诗音（シオン / Sion）的日语语音模型。完整版包含两份最终模型、15条参考语音及日文原文、统一语音页面和图文教程。

## 首次使用先看：这是诗音模型包，需要完整环境

**GPT-SoVITS 原项目与作者团队：[RVC-Boss/GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)，许可证 [MIT](https://github.com/RVC-Boss/GPT-SoVITS/blob/main/LICENSE)。游戏与角色原作：minori《eden*》。诗音微调模型、参考整理和配套页面由 Lunona 发布。本项目不是原作者或官方整合环境。**

本站约307MB的下载包没有Python、CUDA和主程序，不能独立运行。第一次使用请先看 **[完整环境安装与诗音模型导入教程](docs/INSTALL_AND_IMPORT.md)**：包含原作者下载入口、v2ProPlus版本选择、两份权重放到哪个目录、推理页面怎么选择模型，以及配套统一页面的首次路径设置。

- 原版路线：安装支持v2ProPlus的GPT-SoVITS，把两个权重分别复制到GPT_weights_v2ProPlus、SoVITS_weights_v2ProPlus，再刷新和选择。
- 配套路线：已有完整环境后，双击本包启动脚本并指定环境路径，自动加载本包权重，不必手动复制。

## 已有完整环境：从这里打开

1. 在[发布页](https://github.com/Lunona/eden-sion-gpt-sovits/releases/tag/v1.0.2)下载 **`sion-v1.0.2-full-15-references.zip`**，解压到新目录。
2. 双击第一层的 **`启动GPT-SoVITS.cmd`**。首次使用粘贴已有 GPT-SoVITS 完整环境的安装目录；之后会记住。若未自动找到环境 Python，按提示填写该环境的 python.exe。
3. 加载完成后自动打开 **http://127.0.0.1:9872/**。顶部两个大按钮可切换 **直接生成** 和 **参考库**。
4. 用完双击 **`停止GPT-SoVITS.cmd`**，停止本目录启动的两个服务。

本包需要已有的完整 GPT-SoVITS v2ProPlus 环境，使用 Gradio 4.44.1；不包含 Python、CUDA、GPT-SoVITS 主程序或通用预训练依赖。请先按[官方项目](https://github.com/RVC-Boss/GPT-SoVITS)准备环境。GitHub 自动生成的 Source code 压缩包没有权重和参考音频，请下载上述 Release 附件。

## 两个入口怎么用

|入口|操作|
|---|---|
|直接生成|默认选好诗音模型；上传3–10秒参考音频，填写对应准确日文原文，再输入新台词生成。不必加入参考库。|
|参考库|已有完整15条，选择并试听后输入新台词生成，不必先导入。也能新增、分类、保存自己的参考。|

两种方式都需要参考音频。参考库是管理工具；“直接生成”仍需上传参考，并不表示无需参考。

## 中文输入与翻译 API

**两页均支持日文直接生成、中文翻译后生成日语音频。**

- **直接生成**：文本框下方的 **翻译 API 设置（中文输入时配置）** 默认展开。
- **参考库**：展开 **中文翻译设置（使用中文时配置）**。
- 填写服务地址、模型名和 API 密钥，点击 **查看／翻译日文**。可以修改实际朗读的日文，再点击生成。
- 也可以直接点击生成，中文会先翻译，日文绕过翻译；未配置中文翻译或翻译失败时停止，不会退回念中文。
- 纯汉字日文和混合语言请手动选择输入语言。不会内置或自动下载翻译模型。

DeepSeek 配置示例：地址 `https://api.deepseek.com`，模型 `deepseek-flash`，密钥填写自己的 API Key。示例仅是输入提示，未预设服务或密钥。密钥不保存到启动设置、参考库或生成记录；关闭后需重新填写。在线翻译会将输入文字发送给所选服务。

## 包含的模型与参考

- `models/eden_诗音_Sion_GPT.ckpt`：GPT 停顿补样第2轮。
- `models/eden_诗音_Sion_SoVITS.pth`：SoVITS 学习率0.00002，第8轮。
- 15条完整参考、对应日文文本和分类；与此前完整版相同。

模型仅改为可识别的文件名，权重内容未变。SHA256 见 `model-manifest.json`；参考校验见 `reference-manifest.json`。模型列表保留可用的官方底模，不展示作者的中间训练检查点。

## 验证与效果范围
