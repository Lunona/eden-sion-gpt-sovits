# 用完整整合包替换旧版

当前v1.0.2下载附件已替换为完整Windows生成环境，不另发补丁。

1. 停止旧版语音服务，避免9872、9882端口占用。
2. 从[发布页](https://github.com/Lunona/eden-sion-gpt-sovits/releases/tag/v1.0.2)下载全部三个 `eden-sion-windows-portable.7z.001/.002/.003` 分卷，放在一起，从 `.001` 解压到新目录。
3. 双击新目录内 **启动GPT-SoVITS.cmd**。新包已带环境，不再询问已有环境路径；无可用NVIDIA显卡时用 **CPU模式启动.cmd**。
4. 直接生成页已选好参考，输入日文即可生成。可在同页切换参考，或打开参考库。中文输入时重新填写自己的翻译API设置。

新包使用GPT停顿补样第2轮与SoVITS学习率0.00002第8轮，权重内容与此前完整版相同，参考仍是完整15条。

如旧版加入过自己的参考，先备份旧目录中的 `references.json` 以及对应的 `imported`、`curated` 音频；生成结果可按需备份。新包自带的清单不要直接覆盖你的旧备份，可以在参考库中重新加入自己的参考。迁移清单时需要保留对应音频目录，并检查相对路径。API密钥不保存，请重新填写。
