# v1.0.2界面升级

已经下载v1.0.1完整版时，只需升级包`sion-v1.0.2-ui-update.zip`，不用重新下载两份模型或15条参考。

1. 关闭正在运行的参考库启动终端。
2. 将升级包内容解压到原参考库根目录，覆盖`app.py`，加入`translation.py`及新版说明。根目录应同时有`app.py`、`references.json`和`models`文件夹。
3. 用原来的“启动参考库.ps1”命令重新启动。

升级包**不包含**`references.json`、`curated`、`imported`、`generated`或模型文件，不会替换你已有的参考库、修改分类或删除生成结果。不新增Python依赖，不下载翻译模型。

日文可直接生成。中文需配置所选翻译服务，见[中文输入说明](CHINESE_INPUT.md)。如需回到旧界面，用v1.0.1下载包里的`app.py`覆盖回来即可；保留自己的参考库与生成文件。
