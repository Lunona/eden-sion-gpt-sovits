# 从下载到文字生成音频

## 1. 启动同一个页面

下载新版完整版，解压到新目录，双击 **启动GPT-SoVITS.cmd**。首次粘贴已有 GPT-SoVITS 完整环境的目录，例如环境根目录或含 GPT_SoVITS/inference_webui.py 的程序目录。启动器会查找该环境中的 Python；找不到时再按提示粘贴 Python 路径。安装路径只保存在本机 launcher-settings.json，密钥不保存在这里。

等待加载完成后，浏览器会自动打开 http://127.0.0.1:9872/ 。若系统未打开浏览器，将这个地址复制到浏览器地址栏。以后仍双击同一个脚本，不必另开参考库。

![统一页面的两个大入口](images/08-unified-tabs.png)

## 2. 直接生成：手动选参考

1. 点击顶部 **直接生成**。模型默认已选择 eden* 诗音 · GPT 与 eden* 诗音 · SoVITS。
2. 上传3–10秒的参考音频，在参考文本栏填写录音对应的准确日文原文；参考语言选日文。可使用包里的 curated 参考，日文原文在 references.json 中。
3. 在 **要说的内容（中文或日文）** 填写新的台词。这个文本与参考原文是两个不同用途的输入。
4. 日文无需翻译配置。中文时，在文本框下方填写翻译服务地址、模型名称、API 密钥。
5. 点击 **查看／翻译日文**，查看或修改 **实际朗读的日文**。也可直接点击合成语音，由程序完成中文翻译。
6. 点击 **合成语音**，等待播放器出现，试听和下载。语速先保持1，其余参数先保留默认值。

![直接生成中的翻译设置与日文预览](images/09-direct-api.png)

未配置翻译服务时，中文会提示配置并停止；不会生成中文音频。两种输入的输出都是日语。

## 3. 参考库：直接选择已有15条

1. 点击顶部 **参考库**，页面内会显示已有15条参考。
2. 按语气筛选，选参考并试听，核对显示的日文原文。
3. 输入新台词。日文直接生成；中文时展开 **中文翻译设置（使用中文时配置）**，填写地址、模型名和密钥。
4. 可先 **查看／翻译日文** 并修改，再点 **用当前参考生成**。
5. 播放结果并下载。分类用于查找参考，不能保证与分类完全相同的情绪。

完整版不需要先上传或加入参考库。要新增时才展开 **加入新的参考音频（可选）**，上传清晰完整短句，填写名称和与录音一致的日文原文，选择分类，再加入库。

## 4. 配置 API

DeepSeek 示例：

|字段|填写|
|---|---|
|服务地址|https://api.deepseek.com|
|模型名称|deepseek-flash|
|API密钥|自己的 API Key|

也支持兼容 chat-completions 的本地或在线服务。输入框中的示例是提示，不是已配置的默认值。密钥不会保存，关闭后需重新填写。翻译失败、空结果、截断结果或明显非日文结果会停止生成。

## 5. 停止与排查

- 双击 **停止GPT-SoVITS.cmd**，停止本包启动的语音页面和参考库。
- 若提示端口9872或9882被其他程序占用，先关闭之前的语音页面服务，再启动本包；启动器不会停止其他安装目录的进程。
- 若启动失败，查看窗口提示与 launcher-logs 文件夹。确认所用 Python 来自准备好的 GPT-SoVITS 环境。
- 如果 API 设置没出现，先刷新浏览器，确认正在使用新版统一入口。
- 原生 GPT-SoVITS 页面中的“无参考文本”只表示可不填写参考录音原文，并不表示无需参考音频。

模型包需要完整环境；Source code 不含模型与参考音频。源码首次参考库为空，需要自行导入。
