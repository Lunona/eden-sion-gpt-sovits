# 中文输入、日语输出

统一页面的 **直接生成** 与 **参考库** 都有翻译入口。直接生成的文本框下方是默认展开的 **翻译 API 设置（中文输入时配置）**；参考库中展开 **中文翻译设置（使用中文时配置）**。

填写服务地址、模型名称和密钥。点击 **查看／翻译日文**，可修改 **实际朗读的日文** 再生成；也可以直接点生成，程序先翻译再合成日语语音。

自动模式下，有日文假名时直接生成，纯汉字默认按中文翻译。纯汉字日文或混合语言请手动选择输入语言。中文缺少配置、翻译失败或明显错误时停止，不会回退到念中文。

不内置翻译模型，不预设服务或密钥。DeepSeek 示例地址是 https://api.deepseek.com，模型名 deepseek-flash；密钥填写自己的 API Key。支持兼容 chat-completions 的在线或本机服务。在线服务会收到所输入的文本；密钥仅用于当前运行，不写入启动设置、参考库或生成记录。

两种方式仍需参考音频。参考库已预置15条；直接生成可手动上传参考。完整操作见[图文教程](TUTORIAL.md)。
